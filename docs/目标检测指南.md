# 目标检测指南

本指南介绍毕设工坊的目标检测工作流：YOLO 数据格式、训练方式、指标含义与常见问题。

## 数据格式

目标检测使用 **YOLO 格式** 数据集（zip 包）：

```text
my-dataset.zip
├── data.yaml          # 数据集配置
├── images/
│   ├── train/         # 训练图片
│   └── val/           # 验证图片
└── labels/
    ├── train/         # 与图片同名的 txt 标注
    └── val/
```

- `data.yaml` 至少包含 `train`、`val`、`names` 三个字段；
- 每张图片对应一个同名 `.txt` 标注文件，每行格式为 `类别id 中心x 中心y 宽 高`（全部归一化到 0-1）；
- 图片支持 jpg/jpeg/png/bmp/webp。

导入后软件会自动统计图片数量、类别名单和每类标注框数量，并生成类别分布图。

## 模型选择

| 模型 | 特点 | 适合场景 |
| --- | --- | --- |
| YOLOv8n | 最轻量（约 300 万参数），训练最快 | 小数据集、入门毕设、快速跑通 |
| YOLOv8s | 容量更大，精度通常更高 | 中小型检测数据集 |

建议先用 YOLOv8n 跑通全流程，再用 YOLOv8s 做对比实验。

## 关键参数

- **训练轮数（epochs）**：默认 50；小数据集配合早停（patience）即可。
- **图像尺寸（imgsz）**：默认 640；小目标多的场景可以提高，但显存和耗时都会增加。
- **批大小（batch_size）**：默认 16；显存不足时减小。
- **初始学习率（lr0）**：默认 0.01，一般不需要改。
- **早停耐心（patience）**：连续多少轮无提升后停止，0 表示关闭。

## 指标说明

| 指标 | 含义 |
| --- | --- |
| mAP50 | IoU 阈值 0.5 时的平均精度均值，检测任务最常用的主指标 |
| mAP50-95 | IoU 从 0.5 到 0.95 的平均精度均值，更严格的综合指标 |
| Precision | 预测框中正确的比例 |
| Recall | 真实目标被检出的比例 |

实验对比表中主指标为 mAP50。

## 产物说明

训练完成后自动生成：

- `best.pt`：最佳模型权重，可直接用于答辩演示；
- `results.png` / `results.csv`：训练过程曲线与逐轮指标；
- `confusion_matrix.png` / `confusion_matrix_normalized.png`：检测混淆矩阵；
- `val_batch*_pred.jpg`：验证批预测可视化，可直接展示"输入图片 → 检出框"效果；
- `metrics.jsonl` / `summary.json`：指标与可复现记录（参数、设备、耗时）。

## 常见问题

1. **提示"目标检测需要 YOLO 格式数据集"**：zip 内需要 `images/` + `labels/`（或 `data.yaml`），普通分类文件夹结构会被识别为图像分类数据集。
2. **训练报"images not found"**：检查 `data.yaml` 的 `train`/`val` 路径是否与实际目录一致；软件会自动把 `path` 重写为数据集绝对路径，通常不需要手动改。
3. **显存不足**：减小 `batch_size` 或 `imgsz`，或改用 CPU 训练（速度会明显变慢）。
4. **mAP 很低**：小数据集上属正常现象；检查标注质量（框是否准确、类别 id 是否从 0 开始），增加轮数或数据量后再对比。
