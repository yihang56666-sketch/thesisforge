# ThesisForge 引导式神经网络实验平台设计

> 状态：已与用户确认
> 日期：2026-09-13
> 版本：v0.4 目标设计

## 1. 目标

把 ThesisForge 从“功能齐全但入口分散的工作台”升级为“引导式人工智能专业毕设实验平台”。默认入口是“毕设向导”，让不懂机器学习的人也能照着提示一步步完成：数据准备、神经网络设计、优化训练、评估、消融、对比、论文报告。完整工作台保留，随时可切换。

成功标准：

- 首次启动进入向导开始页，10 步可逐步走完，也可随时退出到完整工作台。
- 每一步只显示当前需要的输入与设置，所有输入带中文解释和推荐默认值。
- 支持表格、图像、文本三类数据；神经网络覆盖 MLP、CNN、ResNet 迁移、LSTM/GRU、TextCNN、轻量 Transformer。
- 优化器覆盖 SGD、Momentum、Adam、AdamW、RMSprop；支持学习率调度、早停、权重衰减、梯度裁剪、批量、轮次、随机种子、设备选择。
- 实验自动记录配置、指标、图表、模型；支持重复运行均值±标准差、混淆矩阵、ROC、消融矩阵、实验对比。
- 报告工坊自动把实验整理成论文结构，并在每个向导步骤提供“这一步论文怎么写”的联动说明。
- 训练前有环境自检与网络代价预览；失败时有明确提示与日志定位。

## 2. 产品形态

### 2.1 双模式

- 启动后默认显示“毕设向导”（`#/wizard`）。
- 侧栏保留：总览、数据集、模型训练、实验记录、实验对比、报告工坊、AI 设置、毕设指南。
- 侧栏底部“进入完整工作台”，向导内“回到工作台”，双向切换。
- 向导进度持久化，重新打开后继续上次位置。

### 2.2 向导页面结构

每个向导步骤页统一包含：

- 顶部步骤条：10 步名称与完成状态；已完成绿色，当前高亮，跳过灰色。
- 主区：一个明确的标题、一句人话说明、当前步骤的表单/操作区。
- 右上角：文案固定为主按钮“下一步”；存在校验失败时禁用；“跳过”可跳过当前步骤。
- 左下角：“上一步”（第 2 步起）和“进入完整工作台”。
- 带高级设置的步骤默认折叠高级区，只显示推荐值。

## 3. 向导十步

### 步骤 1：立项

输入：

- 毕设方向：表格数据 / 图像 / 文本 / 综合。
- 论文题目（建议填写）。
- 作者、指导教师（可选）。
- 一句话研究目标（可选）。

功能：保存到项目信息；后续报告工坊自动引用。自动完成条件：题目或方向任一已填写。

### 步骤 2：数据

输入：

- 从内置三件套选择：表格分类示例、图像分类示例、文本分类示例。
- 上传自己的 CSV/图像压缩包/文本 CSV。
- 输入数据集下载 URL。

功能：调用现有数据集 API；导入后展示数据概览：行数、列数、类别分布、缺失值、重复值、数据规模。自动完成条件：存在任一数据集。

### 步骤 3：数据预处理与划分

输入：

- 预处理策略：表格（缺失填充、标准化/归一化）、图像（缩放、翻转增强、归一化）、文本（分词、词表上限）。
- 划分比例：训练/验证/测试，默认 70/15/15。
- 随机种子，默认 42。

功能：保存为“实验模板”的一部分；训练时生效；预览样本。自动完成条件：填过本步并保存。

### 步骤 4：任务与网络架构

输入：

- 任务类型：表格分类/回归、图像分类、文本分类。
- 网络家族：MLP、CNN、ResNet18 迁移、LSTM、GRU、TextCNN、轻量 Transformer。
- 架构参数：层数、隐藏单元/卷积核数、激活函数、Dropout、嵌入维度、是否预训练。

功能：

- 根据任务过滤可用网络。
- 选择后展示“网络代价预览”：参数量、预计训练速度、CPU 友好度。
- 高级设计表格：默认值可直接跑通。

自动完成条件：任务与网络已保存，网络可构建。

### 步骤 5：优化与训练策略

输入：

- 优化器：SGD、SGD+Momentum、Adam、AdamW、RMSprop。
- 学习率、批大小、训练轮数。
- 学习率调度：CosineAnnealing、StepLR、ReduceLROnPlateau、无。
- 权重衰减、早停轮数、梯度裁剪、随机种子、设备（CPU/GPU）。

功能：训练前环境自检：PyTorch 可用、设备可用性、显存状态、依赖组件完整；缺 GPU 组件时给出提示。自动完成条件：优化配置已保存。

### 步骤 6：训练与监控

输入：

- 实验名称、分组（基线/改进/消融/自定义）、备注。
- “开始训练”按钮。

功能：

- 实时显示损失、准确率曲线，训练日志，进度条。
- 支持训练中断与状态保留；非目标进程退出后，已有指标/模型仍可查看。
- 中断后显示“继续训练”不可用时提示重新运行。

自动完成条件：至少一个实验完成（`state=done`）。

### 步骤 7：评估分析

输入：

- 选择已完成实验。
- 重复运行次数 N，默认 1。

功能：

- 展示测试集指标、混淆矩阵、ROC（分类）、训练曲线、最佳轮次。
- 重复运行时输出“均值±标准差”和全部运行记录。
- 导出评估图表。

自动完成条件：当前实验评估图表已生成或已有 summary。

### 步骤 8：消融实验

输入：

- 选择“消融哪些组件”：去掉 Dropout、去掉归一化、去掉残差连接、关闭预训练、去掉数据增强、换优化器。
- 是否保留单项生成结果。

功能：自动创建实验清单，可一键批量创建并依次训练；完成后进入对比。自动完成条件：存在 ≥1 个消融实验或明确跳过。

### 步骤 9：实验对比

输入：

- 勾选参与对比的实验；选择主指标。

功能：现有 `/api/experiments/compare` 升级为按 基线→改进→消融→自定义 排序，最优值高亮，可导出 CSV/Markdown。自动完成条件：生成过一次对比表。

### 步骤 10：报告工坊

输入：

- 论文标题、作者、选题方向（默认取步骤 1）。
- 选择参与报告的实验。

功能：

- 自动生成绪论、相关工作、方法、实验设置、结果与分析、结论结构。
- 插入实验对比表、训练曲线图、混淆矩阵/ROC 图、可复现说明。
- 每个向导步骤提供“这一步论文怎么写”片段，可一键加入对应章节。
- 沿用报告工坊人力改写/AI 润色能力。

自动完成条件：报告文件已生成。

## 4. 网络与优化能力矩阵

| 数据形态 | 网络 | 关键参数 |
|---|---|---|
| 表格 | MLP | 隐藏层、激活、Dropout |
| 表格 | sklearn 基线 | 逻辑回归/随机森林/SVM/GBDT/KNN |
| 图像 | CNN | 卷积层数、每层卷积核数、激活、池化、Dropout |
| 图像 | ResNet18 | 迁移预训练开关、冻结主干开关 |
| 文本 | TextCNN | 卷积核尺寸、嵌入维度 |
| 文本 | LSTM/GRU | 隐藏维度、层数、双向开关、Dropout |
| 文本 | 轻量 Transformer | 注意力头数、层数、d_model、前馈维度、Dropout |

优化器与训练策略统一由通用 Trainer 处理：

- 优化器：SGD、SGD+Momentum、Adam、AdamW、RMSprop。
- 调度器：CosineAnnealingLR、StepLR、ReduceLROnPlateau、无。
- 通用：learning_rate、batch_size、epochs、weight_decay、early_stop_patience、grad_clip、seed、device、class_weights。

## 5. 评估与可复现

每次实验的 run 目录记录：

- `config.json`：完整参数、数据划分、随机种子。
- `metrics.jsonl`：训练/验证逐轮曲线。
- `summary.json`：最终指标与主指标。
- `status.json`：状态与错误信息。
- `best.pt` / `model.pkl`：最佳模型。
- `curves.png`、`confusion.png`、`roc.png`：图表。
- `repro.txt`：Python 版本、设备、耗时、关键依赖版本。

评估能力：

- 分类：accuracy、macro F1、ROC-AUC、混淆矩阵。
- 回归：R²、RMSE、MAE。
- 重复运行：`mean±std`，所有单次运行记录可查。
- 显著性：可选 t 检验（stderr 由运行记录计算）。

## 6. 论文联动

新增 `app/writing.py`，为每步提供模板片段：

- 步骤 1 → 绪论的研究背景与选题来源。
- 步骤 2/3 → 数据来源、数据规模、预处理与划分。
- 步骤 4 → 网络结构与设计理由、参数量。
- 步骤 5 → 优化器与训练策略、超参数说明。
- 步骤 6/7 → 训练过程、最终指标、评估分析。
- 步骤 8 → 消融实验设计与结果讨论。
- 步骤 9 → 对比分析、显著性说明。

报告工坊读取 writer 片段与实验产物，自动生成章节草稿。

## 7. 失败处理

- 训练前环境自检失败：明确提示缺什么、去哪装（GPU 组件提示使用“安装图像训练-GPU版.bat”）。
- 显存不足：捕获 CUDA OOM，提示降低批大小或换 CPU。
- 训练中断：已有日志、指标、模型保留；界面显示“已中断”状态。
- 磁盘不足/参数非法：返回可读错误，前端 toast 展示。
- 所有异常写 `data/logs/launch.log`，并保留现有启动日志能力。

## 8. 工程架构

### 8.1 新增/修改后端文件

- `app/onboarding.py`：向导进度读写、步骤定义、完成条件检测。
- `app/networks.py`：网络注册表与构建函数（表格/图像/文本）。
- `app/trainer.py`：通用 PyTorch Trainer：数据加载、训练循环、优化器/调度器/早停/梯度裁剪/评估。
- `app/writing.py`：论文片段模板。
- `app/experiments.py`：扩展消融与重复运行统计。
- `app/main.py`：新增 `/api/wizard`、`/api/networks/estimate`、`/api/env/check`、`/api/writing/<step>`、消融相关接口。
- `app/config.py`：新增项目信息与向导进度文件常量。
- `app/catalog.py`：扩展任务/模型参数 schema，供向导表单动态渲染。

### 8.2 前端

- 保留现有 `web/index.html` 侧栏结构。
- 新增 `web/wizard.js`：向导路由、步骤渲染、进度持久化、动态表单生成。
- 修改 `web/app.js`：`#/wizard` 路由、侧栏入口、导航切换。
- 修改 `web/style.css`：步骤条、向导布局、高级折叠、状态色；沿用现有设计系统。

### 8.3 数据模型

向导进度与项目信息保存到 `data/project.json`：

```json
{
  "version": 1,
  "project": {"title": "", "author": "", "advisor": "", "direction": "", "goal": ""},
  "steps": {
    "1": {"state": "todo", "completed": false, "saved_at": null},
    "4": {"state": "todo", "completed": false, "saved_at": null}
  },
  "active_step": 1,
  "updated_at": "..."
}
```

实验模板（用于步骤 3/4/5）保存在 `data/experiment_template.json`。

## 10. 分期实施

这是大范围改造，按可独立交付的子系统分期：

1. Sprint 1：向导框架与状态后端（本设计文档 + 向导 UI + `/api/wizard` + 项目信息持久化）。
2. Sprint 2：网络注册表、通用 Trainer、catalog 扩展、训练脚本升级。
3. Sprint 3：评估增强、消融自动生成、重复运行统计。
4. Sprint 4：论文片段、报告联动、环境自检与网络代价预览。
5. Sprint 5：构建依赖升级、打包、发布说明、全量回归与发布。
