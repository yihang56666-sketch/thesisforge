# 自动调参指南

## 什么时候用

先跑通一个基线模型，再开始自动调参。调参是“寻找更好的超参数”，不是解决数据质量或标注错误的方法。毕设里通常只需围绕一个基线模型调参，把结果写进“算法改进”章节即可。

## 三种模式

- **TPE 贝叶斯搜索（推荐）**：默认模式，适合 10~50 轮搜索，能根据历史结果自适应选择参数。
- **Hyperband 剪枝**：适合训练轮数较多、单轮训练较慢的场景；会提前淘汰表现差的候选，缩短总时间。
- **小规模网格**：适合参数很少、想覆盖固定候选组合的场景。当前实现会自动裁剪候选规模，避免组合爆炸。

## 怎么选指标

- 分类任务优先用 **Accuracy**、**F1** 或 **AUC**。
- 类别不平衡时不要只看 Accuracy，建议用 **F1** 或 **AUC**。
- 回归任务用 **RMSE**、**MAE** 或 **R²**。
- 如果不清楚该选什么，就用“主指标”，它会沿用普通实验的对比口径。

## 使用流程

1. 在数据集页载入数据。
2. 在模型训练页选择任务和模型。
3. 在“自动调参”卡片设置搜索轮数、评估指标、搜索模式。
4. 点击“开始自动调参”，等搜索完成。
5. 查看最佳分数、最佳参数和历史轮次。
6. 把最佳参数填回普通实验表单，再跑一次正式训练并命名分组，方便进入对比表和报告。

## 注意事项

- 每个候选参数都会真实训练一次，训练耗时按轮数叠加。
- 建议先用小数据集或较少轮数试跑，确认没问题后再扩大搜索规模。
- 自动调参的结果不会自动加入普通实验列表，防止搜索过程和正式实验混在一起。
- 论文里至少要说明：搜索空间、搜索算法、评估指标、搜索轮数、随机种子。
