# 时间序列预测指南

本指南介绍毕设工坊的时间序列预测工作流：数据要求、划分原则、模型选择、参数含义与常见问题。

## 数据要求

- 数据格式为 CSV（表格数据），目标列必须全部为数值，未指定时默认使用最后一列。
- 除目标列外的数值列会自动作为特征输入；文本列和非数值列会被忽略。
- 样本量至少要满足 `回看窗口 + 预测步数 + 2`，否则会提示样本不足。

## 划分原则

时间序列与分类/回归任务最大的不同是**必须按时间顺序划分**，不能随机打乱：

1. 先按时间顺序切出训练段、验证段、测试段（默认 60% / 20% / 20%，可在向导步骤 3 调整）；
2. 标准化均值和方差**只从训练段计算**，验证段和测试段用同一组参数变换，避免未来信息泄漏；
3. 滑窗只在各自段内生成，跨段不会拼窗口；
4. DataLoader 全程 `shuffle=False`，保证时序因果性。

实验记录和对比表中的划分方案会显示为 `chronological train/val/test`，这是答辩时解释"无泄漏"的直接证据。

## 模型选择

| 模型 | 适合场景 | 特点 |
| --- | --- | --- |
| LSTM | 中等长度依赖，多变量预测 | 稳定，参数量适中，最常用基线 |
| GRU | 与 LSTM 相同，数据量偏小或想快速跑通 | 结构更轻，训练更快 |
| Transformer | 较长时间依赖、需要注意力解释 | 参数量最大，小数据上可能过拟合 |

建议先跑 LSTM 作为基线，再用 GRU 和 Transformer 做对比，形成三组实验放进对比表。

## 关键参数

- **回看窗口（lookback）**：用过去多少个时间步预测未来，默认 12。
- **预测步数（horizon）**：一次预测未来多少步，默认 1。
- **隐藏单元数 / 模型维度**：模型容量，数据少时保持默认即可。
- **学习率**：默认 0.001，配合余弦退火通常够用。

## 产物说明

训练完成后自动生成：

- `forecast.png`：预测序列与真实序列对比图；
- `pred_vs_true.png`：逐样本预测值 vs 真值散点；
- `curves.png`：训练/验证损失曲线；
- `metrics.jsonl` / `summary.json`：指标与可复现记录（种子、划分方案、设备、耗时）；
- `best.pt` + `predict.py`：最佳模型与预测脚本，可直接答辩演示。

主指标为测试集 `R2`，同时输出 MAE、RMSE、MSE，全部进入实验对比表。

## 常见问题

1. **提示"目标列必须全部为数值"**：检查 CSV 目标列是否有空值或非数字字符，先清洗再导入。
2. **提示"时间序列样本不足"**：减少回看窗口或预测步数，或补充更长的历史数据。
3. **提示"测试/验证比例过大"**：训练段为空，调小测试/验证比例。
4. **验证损失震荡**：减小学习率或增大批大小；小数据上优先 LSTM 而不是 Transformer。
