# 毕设全流程分析（人工智能专业）

> 本文档是「毕设指南」页面的完整版。核心结论：**毕设是一条流水线，每一步的产出是下一步的输入**；
> 数据决定上限、实验决定说服力、分析决定深度、写作决定呈现。

## 总览

```
选题开题 → 文献调研 → 数据获取与EDA → 基线模型 → 算法改进
    → 实验管理 → 结果分析 → 论文撰写 → 查重答辩
```

时间分配建议（约一学期）：选题开题 10%、文献 10%、数据 15%、实验（基线+改进）35%、分析 10%、写作 20%。

---

## ① 选题与开题

- **做什么**：确定研究方向；明确「用什么数据 + 什么模型 + 改进什么」。
- **注重**：
  - 大小适中：纯调包（只跑现成模型）不够毕业，太大（自研新算法）做不完；
  - 可行性三问：数据公开可得吗？我的算力（CPU/单卡）跑得动吗？有可改进的空间吗？
  - 题目表述：对象 + 方法 + 问题，如「基于改进 ResNet18 的车辆图像分类方法研究」。
- **产出**：开题报告、任务书。
- **衔接**：选题决定后面所有步骤；开题前先用本工具载入候选数据集验证可得性。

## ② 文献调研

- **做什么**：检索 10-20 篇相关论文（知网、Google Scholar、Papers With Code），确定 1-2 个基线方法。
- **注重**：优先近 3-5 年；为每篇记录「数据集/指标/核心思路」三要素；找到该任务的 SOTA 数字作为参照。
- **产出**：文献综述初稿、基线清单。
- **衔接**：基线方法记下来，到「模型训练」页复现。

## ③ 数据获取与 EDA

- **做什么**：从 Kaggle / HuggingFace / UCI / 政府开放平台获取数据；检查规模、类别平衡、缺失值、分布。
- **注重**：
  - **数据决定上限**：垃圾进垃圾出；
  - **防数据泄漏**：先划分训练/测试集，再在训练集上做标准化等预处理；
  - 类别不平衡要在建模时处理（类权重/过采样/宏平均 F1）。
- **产出**：数据集卡片（来源/规模/许可证）、EDA 图表。
- **衔接**：本工具「数据集」页一键完成载入 + EDA + AI 解读。

## ④ 基线模型

- **做什么**：先跑通最简单的基线，拿到第一组可信指标。
- **注重**：固定随机种子；统一评价指标；记录完整配置保证可复现；测试集在改进阶段之前绝不参与任何决策。
- **产出**：基线指标 + 训练日志。
- **衔接**：基线是后续所有「改进了多少」的参照系。

## ⑤ 算法改进（毕设的创新点所在）

- **做什么**：做 1-2 个改进点：网络结构、损失函数、数据增强、特征工程、集成、超参数搜索。
- **注重**：
  - **消融实验**：逐个开关改进模块，证明每一项都有效——这是答辩核心证据；
  - 每次只改一个变量；改进要有动机（为什么这样改应该有效）。
- **产出**：改进模型 + 消融实验表。
- **衔接**：「模型训练」页改参数重跑即可，所有 run 自动留档。

## ⑥ 实验管理

- **做什么**：统一实验设置，完成对比表（基线 vs 改进 vs 文献 SOTA）与训练曲线。
- **注重**：每组实验记录超参与种子；关键结论最好多 seed 取均值±方差。
- **产出**：实验对比表、曲线图。
- **衔接**：「实验记录」页就是实验管理器，可直接勾选进报告。

## ⑦ 结果分析

- **做什么**：混淆矩阵、ROC、特征重要性、误差案例分析；解释为什么有效/无效。
- **注重**：分析要有因果解释，不是罗列数字；每一张图都要在文中引用并解读。
- **产出**：实验分析章节文字 + 图表。
- **衔接**：点「AI 分析结果」获得解读草稿；图表自动插入报告第四章。

## ⑧ 论文撰写

- **做什么**：按学校模板撰写五章：绪论 / 相关技术 / 数据与方法 / 实验分析 / 总结展望。
- **注重**：摘要最后写；图表统一编号；参考文献格式核对；先搭骨架再填肉。
- **产出**：论文初稿（.docx）。
- **衔接**：「报告工坊」生成标准骨架初稿（封面/摘要/五章/图表/参考文献），导出后精修。

## ⑨ 查重与答辩

- **做什么**：查重降重、盲审修改、准备答辩 PPT 与现场演示。
- **注重**：PPT 少字多图；准备好「为什么这个改进有效」「指标为什么这样选」的答案；现场演示要录屏备份。
- **产出**：终稿、答辩 PPT。
- **衔接**：报告导出后本地精修；用「实验记录」的图表做 PPT 素材。

---

## 常见踩坑清单

1. 测试集参与了调参（信息泄漏），最终指标虚高；
2. 只报告准确率，类别不平衡下毫无意义；
3. 改进没有消融，答辩时被问「每个模块贡献多少」答不上；
4. 实验没记种子和超参，后期无法复现；
5. 论文图表是截图拉伸的模糊图——用本工具生成的 PNG（130 dpi）即可；
6. 摘要写了半页方法没有结果数字——摘要必须含关键指标。
