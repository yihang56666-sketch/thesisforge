# 毕设实验报告（演示数据版）

> 项目：毕设工坊 ThesisForge
> 说明：本报告用于验证软件从“数据准备 → 基线 → 改进 → 重复实验 → 消融 → 对比 → 报告导出”的完整流程。图像部分使用脚本即时生成的合成数据，**不是真实医学数据，不得据此得出医学结论**；另用乳腺癌威斯康星公开数据集验证表格分类流程。

## 1. 实验环境

- CPU 训练（无 GPU），Python 3.13 + PyTorch CPU 版
- 实验台账自动落盘：每个实验保留配置、种子、日志、指标、曲线、混淆矩阵
- 全部实验通过本地服务接口创建、轮询、对比与导出，复现命令见文末

## 2. 数据集

### 2.1 图像数据集（合成演示）

- 共 360 张 64×64 彩色 PNG，4 类各 90 张：`class_0` 亮蓝病灶、`class_1` 橙黄纹理、`class_2` 浅绿双团、`class_3` 粉红棋盘
- 每张图包含形状/纹理差异、像素级噪声与亮度/对比度扰动，标签由生成脚本固定（种子 `20260913`）
- 划分：训练 216 / 验证 72 / 测试 72，测试集全程不参与模型选择

### 2.2 表格数据集（真实公开数据）

- 乳腺癌威斯康星公开数据集 569 行，二分类任务
- 逻辑回归使用 5 折交叉验证选参；MLP 使用训练/验证/测试划分

## 3. 实验设计

| 编号 | 实验 | 任务 | 模型 | 关键配置 |
| --- | --- | --- | --- | --- |
| A1 | 图像基线 | 图像分类（4 类） | 3 层 CNN | SGD，lr=0.01，6 epoch，ReLU，Dropout=0.3，无调度 |
| A2 | 图像改进 | 图像分类（4 类） | 3 层 CNN | AdamW，lr=0.001，15 epoch，余弦调度，GELU，Dropout=0.4，权重衰减 1e-4，早停 4，梯度裁剪 1.0 |
| A3-A5 | 改进重复 | 图像分类（4 类） | 同 A2 | 仅随机种子不同（42/43/44） |
| A6-A9 | 改进消融 | 图像分类（4 类） | 同 A2 | 每次只改一个变量：Dropout=0、权重衰减=0、优化器=SGD、调度=None |
| B1 | 表格基线 | 二分类 | 逻辑回归 | C=1.0，max_iter=1000，5 折交叉验证 |
| B2 | 表格改进 | 二分类 | MLP | 128-64 隐层，GELU，AdamW，余弦调度，早停 |

评价指标统一为测试集准确率、宏平均 F1/精确率/召回率，表格任务另加 ROC AUC。

## 4. 实验结果

完整对比表见 `docs/实验对比_演示数据.md` / `.csv`，Word 草稿见 `docs/报告草稿_*.docx`。核心结果：

| 实验 | 测试准确率 | 宏平均 F1 | 测试损失 |
| --- | --- | --- | --- |
| 图像基线 A1 | 1.000 | 1.000 | 0.842 |
| 图像改进 A2 | 1.000 | 1.000 | 1.166 |
| 改进重复 A3-A5 | 1.00±0.00 | 1.00±0.00 | 0.653±0.410 |
| 消融-丢弃率=0 | 1.000 | 1.000 | 1.147 |
| 消融-权重衰减=0 | 1.000 | 1.000 | 1.166 |
| 消融-优化器=SGD | 0.500 | 0.421 | 1.318 |
| 消融-调度=None | 1.000 | 1.000 | 1.166 |
| 表格基线 B1 | 0.965 | 0.962 | - |
| 表格改进 B2 | 0.965 | 0.962 | 0.086 |

## 5. 结果分析

1. **软件闭环验证成功**：11 个实验全部由向导/批量接口创建、后台训练、自动落盘，并在无人工干预情况下完成对比表与 Word 报告导出。
2. **消融实验有效**：改进配置整体用 SGD 替代 AdamW 时，测试准确率从 1.000 降至 0.500（接近随机），宏平均 F1 降至 0.421，说明在该任务与学习率设置下优化器选择是主要影响因素；单开 Dropout、权重衰减、余弦调度的消融均不降低最终指标，说明在合成数据上这些模块没有造成负向影响，符合设计预期。
3. **重复实验有效**：相同配置、不同种子的 3 次重复结果一致（1.00±0.00），表明实验平台种子固定与划分可复现机制生效；测试损失存在波动（0.653±0.410），保留方差信息有利于答辩展示。
4. **表格流程有效**：逻辑回归与 MLP 在乳腺癌公开数据上测试准确率均约 0.965，ROC AUC 约 0.996，交叉验证、特征重要性、ROC 曲线、混淆矩阵均已生成，可直接用于后续真实数据实验的对照写法。
5. **必须诚实说明**：合成图像类别间颜色对比度显著，任务偏易，因此基线/改进都达到 100%，该组数字不能代表真实医学影像难度；真实毕设应替换为公开医学影像数据（LIDC、ISIC、CheXpert 等）后按同一流程重跑。

## 6. 结论与展望

平台已经覆盖毕设实验的主体工作流：数据 EDA、基线、算法改进、多模型对比、批量重复、一键消融、AI 解读、论文报告导出。演示实验证明了流程可复现、指标可对比、图表可留档。

后续用真实数据集开展实验时，建议在同一平台内固定三件事：统一随机种子、统一测试集划分、只对验证集调参，然后以本文档的第 3 节表格为模板完成正式实验章节。
