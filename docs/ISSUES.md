# 毕设常见问题预判与对策

> 做毕设会踩的坑，大部分可以提前避开。这里按类别列出问题、对策、以及本工具承担的部分。
> 总原则：**工具负责流程和格式，你负责判断和文字。**

## 一、论文格式类（格式审查/盲审最容易挂的地方）

| 问题 | 对策 | 工具承担 |
| --- | --- | --- |
| 字号/行距/边距不符学校规范 | 生成稿已按通用规范（宋体小四、1.5 倍行距、A4 边距 2.6/2.6/3.0/2.5）排版；拿到学院模板后用 Word 样式刷逐项核对 | 报告工坊自动排版 |
| 目录空白或页码不对 | 目录是 Word 自动域，打开后 Ctrl+A → F9 更新；页码域同理 | 已内置 TOC/PAGE 域 |
| 表格用网格线被批"不学术" | 学位论文要求三线表：工具自动生成（顶/底线 1.5 磅、栏目线 0.75 磅、无竖线） | 已内置 |
| 图表编号混乱、图文不对应 | 编号按"图 4-2"章节式自动生成；正文中引用图号后再插图 | 已内置 |
| 参考文献格式错 | 已按 GB/T 7714 风格生成；**至少补到 15 篇**、补与选题直接相关的文献 | 给出模板 |
| 封面/页眉与学校模板不同 | 学校字段用于封面与页眉，但各校封面样式差异大，通常要复制内容进学校模板 | 提供字段占位 |

## 二、查重与 AIGC 检测类

| 问题 | 对策 |
| --- | --- |
| AIGC 检测率过高（知网/维普/万方等） | 先在「报告工坊 → AIGC 自检」看特征分与问题定位；用「降 AI 味改写」处理模板腔、句长过于均匀、列表体；**最可靠的做法是把 AI 初稿当参考资料，用自己的话重写**。各家检测算法不公开且持续更新，任何工具都不能保证结果，请遵守学校 AIGC 使用规定 |
| 查重率过高 | 公式、参考文献、自己实验数据不算重复；重复主要在"背景综述"——用自己的逻辑重组文献而不是摘抄；工具生成的模板文字务必重写 |
| 盲审被批"像模板" | 摘要含具体数字、结论回应开题目标、每张图都有文中引用和解读 |

## 三、实验与算法类

| 问题 | 对策 | 工具承担 |
| --- | --- | --- |
| 测试集泄漏（调参时用了测试集） | 调参只看交叉验证，测试集最后只碰一次 | 工具内部已按此实现 |
| 只看 accuracy，类别不平衡下虚高 | 同时看宏平均 F1 / AUC / 混淆矩阵 | 自动生成全套指标 |
| 结果不可复现 | 固定随机种子，记录超参 | 训练默认 seed=42，实验留档 |
| 改进无消融，答辩答不上 | 每个改进点单独开关各跑一次 | 多组实验自动留档对比 |
| 单次结果碰运气 | 关键结论换 2-3 个种子重跑，报均值±方差 | 改 seed 再跑即可 |

## 四、数据类

| 问题 | 对策 |
| --- | --- |
| 数据集许可证不允许学术使用 | 下载前看 License（Kaggle/HuggingFace 页面都有）；论文里注明来源 |
| 数据量太小说服力不足 | 交叉验证 + 数据增强；或换/合并公开数据集 |
| 类别严重失衡 | class_weight / 过采样 / 分层抽样（工具已用分层划分与宏平均指标） |
| 缺失值/异常值随手删 | 先分析原因再决定填充或剔除，EDA 图表留证 |

## 五、工程与算力类

| 问题 | 对策 |
| --- | --- |
| GPU 显存不够（OOM） | 减小 batch_size 或 image_size（训练页可直接改） |
| 训练中断前功尽弃 | 工具逐 epoch 落盘指标、保存 best.pt，中断后改小 epochs 续跑 |
| 实验多到记不清 | 所有 run 自动留档于 data/runs/，配置/日志/图表可回溯 |
| 换电脑丢环境 | requirements.txt + data/ 目录整体拷贝 |

## 六、时间与答辩类

| 问题 | 对策 |
| --- | --- |
| 前松后紧 | 按总览页清单推进：第 4 周前必须有基线，第 8 周前完成改进，留 4 周写论文 |
| 答辩被问"创新点在哪" | 用消融表回答：每个模块开/关的指标差就是创新点的贡献 |
| 现场演示翻车 | 提前录屏备份；工具全本地运行，无网络依赖 |
