# 新手使用手册

> 这份手册按“双击安装包 → 跑第一组实验 → 生成报告”的顺序写。你只需要按页面提示操作，遇到看不懂的地方先看括号里的说明。

## 1. 启动软件

1. 下载 Windows 离线整合包 `ThesisForge-v0.5.1-win64-offline.zip`。
2. 解压到一个英文路径，例如 `D:\ThesisForge`。路径里不要有压缩包占用的乱码或异常符号。
3. 双击 `ThesisForge.exe`。软件会默认打开桌面窗口。
4. 如果桌面窗口没出现，先等 5-10 秒；仍然没有就看目录里的 `data\logs\launch.log`。
5. 想直接用浏览器操作，可以打开 `ThesisForge.exe --browser`。

> 不要删除包内的 `runtime` 文件夹，里面是 Python 和依赖。

## 2. 进入毕设向导

第一次启动默认进入“毕设向导”。它不是替代完整工作台，而是把流程拆成 10 步：

1. 立项：填题目、作者、研究目标。
2. 数据：选内置示例，或导入自己的 CSV/Excel/图像数据。
3. 预处理与划分：保留默认推荐值即可。
4. 任务与网络架构：选任务类型和模型。
5. 优化与训练策略：默认参数就够跑通。
6. 训练与监控：点开始训练，实时看曲线和日志。
7. 评估分析：看测试指标、混淆矩阵、ROC 或预测图。
8. 消融实验：基于基线或改进模型一键派生。
9. 实验对比：勾选实验生成对比表。
10. 报告工坊：生成 Word 初稿。

每一步都可以“跳过”，但建议按顺序做完。系统会自动保存进度，随时可以关掉软件继续。

> 数据载入后会自动做质量体检。如果发现缺失值、重复样本、类别分布不均或样本规模偏小，数据详情页和向导数据页会显示黄色“数据质量提醒”。这些提示先处理或写进研究局限，不要假装没看见。

## 3. 跑第一组实验

如果你还没准备好数据，先用内置示例：

1. 进入“毕设向导 → 数据”。
2. 选择 `iris`、`breast_cancer` 或 `digits` 这类小数据集。
3. 进入“任务与网络架构”，先用推荐模型跑通，比如 `random_forest`、`logistic_regression` 或 `cnn`。
4. 在“优化与训练策略”页保留默认参数。
5. 点“开始训练”，等状态变成 `done`。
6. 在“实验记录”里打开这次实验，看指标、曲线和图表。

> 第一次的目标不是拿到最优结果，而是确认整条链路能跑通。跑通后再考虑换模型和调参。

## 4. 补齐毕设需要的三类实验

论文里至少要有基线、改进、消融三类实验：

1. **基线实验**：用最简单、最经典的模型先跑一次，命名成“基线”。
2. **改进实验**：换更强的模型或调参后再跑一次，命名成“改进”。
3. **消融实验**：在改进实验详情页用“一键消融”逐个修改关键参数，验证每个改动到底有没有贡献。

实验名称和分组一定要写清楚，否则后面报告和对比表会分不出哪一组是哪一组。

## 5. 看懂结果

不同任务看重点不同：

- **表格/文本/图像分类**：先看准确率和宏平均 F1，再看混淆矩阵找主要误分类类别。
- **目标检测**：先看 mAP50 和 mAP50-95，再看精确率、召回率和预测可视化。
- **语义分割**：看 IoU、Dice 和像素准确率，重点检查边界是否糊。
- **时间序列预测**：看 MAE、RMSE 和预测曲线，检查是否滞后或只在均值附近打转。

> 不要只看准确率。类别不均衡、漏检、边界模糊和预测滞后都会让准确率看起来不错但实际不可用。

## 6. 生成报告

1. 进入“报告工坊”。
2. 勾选要写入报告的实验。
3. 填标题、作者、学院、专业、指导教师。
4. 选择是否启用 AI 草稿。不启用也会生成结构完整的研究骨架。
5. 点生成 `.docx`。
6. 打开 Word 后按 `Ctrl+A` 再按 `F9`，更新目录和页码。
7. 检查摘要、方法、实验分析、结论和参考文献，用你自己的话润色。

报告默认包含：

- 中英文摘要；
- 研究背景与研究内容；
- 任务族文献综述；
- 研究方法与技术路线；
- 数据集与预处理；
- 实验环境、指标分析、结果对比；
- 工作总结、主要结论、研究局限、未来展望；
- 参考文献和致谢。

## 7. 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 双击后没反应 | 看 `data\logs\launch.log`，检查是否被杀毒软件拦截或路径不完整 |
| 训练失败 | 在实验详情页看错误日志，通常先检查数据格式和目标列 |
| 显存不足 | 减小 batch size、图像尺寸或模型层数 |
| 想用图像训练 | 离线包内双击“安装图像训练-CPU版.bat”或 GPU 版 |
| 报告目录不显示页码 | 在 Word 中按 `Ctrl+A` 后按 `F9` 更新域 |
| 结果不可复现 | 使用相同数据划分、随机种子和模型参数再跑一次 |

## 8. 交付前检查

1. 数据来源、预处理和划分方式是否写清楚了。
2. 数据质量提醒中提到的问题是否处理了，或者在报告中说明了局限。
3. 是否有基线、改进、消融实验。
4. 是否记录了随机种子、超参数和实验环境。
5. 是否同时报告整体指标和误差来源。
6. 报告中的图表编号、目录、页码是否更新。
7. 文献是否补充到与你的选题直接相关的领域。
8. 结论是否承认样本规模和真实场景的局限。
