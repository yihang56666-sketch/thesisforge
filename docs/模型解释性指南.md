# 模型解释性指南

模型解释性不是“模型更准了”，而是回答另一个问题：**模型为什么这样判断？** 在毕设中，它可以放在实验分析、模型讨论或改进依据部分。它不适合用来证明模型正确，只适合展示模型是否关注了合理线索。

## 自动生成的解释

训练完成后，不同任务会自动生成对应的解释产物，并出现在「实验记录」的产物区：

| 任务 | 模型 | 产物 | 方法 |
| --- | --- | --- | --- |
| 图像分类 | CNN / ResNet18 | `grad_cam.png` | Grad-CAM |
| 文本分类 | LSTM / GRU / TextCNN / Transformer | `token_attribution.json`、`token_attribution.png` | token 梯度归因 |
| 表格分类 / 回归 | MLP | `permutation_importance.png`、`permutation_importance.json` | 置换重要性 |

如果解释工具因模型结构、显存、数据批次等原因失败，训练结果不会被中断，日志里会提示“模型解释生成跳过”。

## 图像 Grad-CAM

Grad-CAM 会在 CNN 的最后一个卷积层上计算目标类别的梯度，再把梯度加权映射回特征图，得到一个热力图。红色区域表示模型对该预测类别的关注更强。

读图时注意：

- 高亮区域落在目标物体上，说明模型可能学到了相关视觉特征。
- 高亮区域落在背景、边框、水印或无关纹理上，提示数据可能有捷径特征。
- 多张样例一起看更有说服力；只看单张图不能说明模型整体行为。

论文中可以写：  
“为观察 CNN 的判别依据，本文使用 Grad-CAM 可视化模型在测试样例上的关注区域。图中高亮区域表示对预测类别影响较大的图像位置。”

## 文本 token 归因

文本模型会对词向量 embedding 计算目标预测分数的梯度，梯度范数越大，表示该 token 对当前预测的贡献越大。图表只展示影响最大的 token。

读图时注意：

- “很好”“很差”“失败”等词权重高，通常符合情感分类直觉。
- 标点、停用词或位置编号权重过高，说明模型可能依赖了无关信号。
- 该方法只反映当前模型和当前样本的解释强度，不是全局特征重要性。

论文中可以写：  
“为分析文本模型的判别依据，本文基于 embedding 梯度计算 token 归因强度，并选取贡献最大的词进行可视化。”

## 表格置换重要性

置换重要性会把某个特征列随机打乱，然后观察模型指标下降多少。下降越多，说明该特征越重要；下降很小，说明模型对该特征依赖较弱。

读图时注意：

- 数值高的特征是模型当前依赖较强的特征。
- 如果和领域常识冲突，应先检查数据泄漏、时间顺序错误、预处理错误或类别不平衡。
- MLP 的置换重要性不等于因果重要性，也不能直接推广到所有模型。

论文中可以写：  
“为分析 MLP 模型的输入依赖，本文对验证/测试样本进行特征置换，并以指标平均下降量衡量特征重要性。”

## 使用边界

- 解释图是辅助分析，不是实验准确性的替代品。
- 不能只用解释结果证明模型有效，应配合混淆矩阵、F1、AUC、回归指标等一起看。
- 如果解释图提示模型依赖错误线索，应回到数据集、预处理或特征设计部分排查。
- 写入论文时建议注明方法、样本来源、评估集和随机种子，保证可复现。
