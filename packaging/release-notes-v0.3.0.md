# 毕设工坊 ThesisForge v0.3.0

v0.3.0 把毕设实验闭环做完整：从基建、基线、改进到消融实验都能在软件里分组留档，并一键生成论文用的对比表。

## 本次新增

- **桌面窗口（EXE/离线包默认形态）**：双击直接打开 Windows 原生窗口，WebView2 缺失时自动降级为浏览器；也可用 `--browser` / `--no-browser` 切换形态。
- **实验分组**：训练时可选择「基线 / 改进 / 消融 / 自定义」分组并填写实验名称与备注；旧实验可随时编辑分组，报告与对比表按统一分组口径展示。
- **实验对比页**：勾选已完成实验即可查看主指标条形图、逐指标对比表与热力矩阵；一键下载 CSV 或复制 Markdown 表格，方便直接粘进论文。
- **实验排序与报告升级**：全部实验按 基线→改进→消融→自定义 排序，同组内按主指标降序；报告第 4 章对比表新增「实验分组」列。
- **本地服务防护与稳定性**：Host/Origin 双重校验、实验路径白名单、WebView2 缺失/启动失败降级、端口自动避让等检查均已有测试覆盖。

## 本次修复

- 独立 EXE 改为无控制台窗口形态（GUI 子系统），双击不会再先弹一个空白黑终端。
- 新增启动日志 `data/logs/launch.log`：窗口没出现时，从这里查看启动/降级/致命错误原因；致命错误会直接弹系统提示框。
- 离线包同样使用无控制台启动器，并可共用同一份启动日志排查。

## 资产

| 文件 | 说明 |
| --- | --- |
| `ThesisForge-v0.3.0-win-x64.exe` | 独立单文件版：自带 Python 与表格/文本/报告全部依赖，默认桌面窗口（不含 PyTorch） |
| `ThesisForge-v0.3.0-win64-offline.zip` | Windows 离线整合包：内嵌 Python，解压后双击 `ThesisForge.exe`，可自行安装 CPU/GPU 版 PyTorch 做图像训练 |

## 已知边界

- 独立单文件版为控制体积不包含 PyTorch，图像分类请使用离线整合包。
- 桌面窗口依赖 WebView2；未安装时程序会自动改用浏览器打开，不影响使用。
- AIGC 检测工具无法保证学校检测系统结果，AI 初稿应结合自己的理解重写并遵守学校规定。
