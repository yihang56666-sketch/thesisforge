# 毕设工坊 ThesisForge v0.2.1

v0.2.1 在 v0.2.0 基础上完成一轮方法严谨性与安全加固，并修复了打包形态下训练子进程无法启动的问题。

## 本次改进

- 图像分类改为「训练集 / 验证集 / 测试集」三段划分：权重在训练集更新，模型与超参数依据验证集选择，测试集只在最终评估时使用一次，测试集指标不再被反复查看。
- 表格/文本任务保留测试集拆分 + 交叉验证，固定随机种子，报告用词明确区分验证集与测试集。
- 安全加固：出站下载逐跳 SSRF 校验（拒绝内网/环回/保留地址）并限 1GB；zip 导入防 zip-slip；本机服务校验 Host/Origin（防 DNS rebinding 与跨站写请求）；参数白名单 + 类型/范围夹取，防止 API 直传极端参数。
- AIGC 降 AI 味改为确定性改写（同一输入永远同一结果），实验结果可复现。
- 修复 PyInstaller EXE 内训练子进程无法启动（frozen 分支改用 `--tf-worker`）。
- 离线整合包改为双击 `ThesisForge.exe` 启动，自动选择可用端口。
- 新增单元测试（路径安全、SSRF、参数清洗、导入/解压、报告文件名等）与端到端回归脚本。

## 资产

| 文件 | 说明 |
| --- | --- |
| `ThesisForge-v0.2.1-win-x64.exe` | 独立单文件版：自带 Python 与表格/文本/报告全部依赖，双击即用（不含 PyTorch） |
| `ThesisForge-v0.2.1-win64-offline.zip` | Windows 离线整合包：内嵌 Python，解压后双击 `ThesisForge.exe`，可自行安装 CPU/GPU 版 PyTorch 做图像训练 |

## 已知边界

- 独立单文件版为控制体积不包含 PyTorch，图像分类请使用离线整合包。
- AIGC 检测工具无法保证学校检测系统结果，AI 初稿应结合自己的理解重写并遵守学校规定。
