# 毕设工坊 ThesisForge v0.5.1

v0.5.1 重点提升报告的论文写作深度，让中英文摘要、任务方法论和单个实验分析直接基于真实实验结果生成。

## 本次新增

- **中文摘要与结论增强**：无 AI 草稿时，自动基于数据集、基线、改进方案、消融结果和评估集生成更具体的摘要与结论。
- **英文摘要增强**：英文摘要根据真实数据集、模型与主指标生成，不再使用固定占位文案。
- **任务方法论说明**：报告按任务家族补充实验设计说明，覆盖目标检测、语义分割、图像分类、文本分类、表格分类和时间序列预测。
- **单个实验分析增强**：运行级分析直接报告主指标、其余指标、相对基线变化、过拟合/欠拟合迹象、类别不平衡与任务专属指标解释，替代“等 AI 接口”的占位文案。
- **图表引用段落**：每个实验的图表自动生成“图 X 至图 Y”的分析引导，提醒结合指标表、训练曲线和数据划分交叉核对。
- **论文结构增强**：新增任务族文献综述、研究方法与技术路线、评价指标分析、工作总结、主要结论、研究局限与未来展望章节，让无 AI 草稿的报告也更接近可提交论文骨架。
- **向导分类增强**：立项方向区分图像分类、目标检测、语义分割、文本分类、表格预测和时间序列预测；旧方向仍可兼容。
- **数据质量提醒**：数据集体检后，缺失值、重复样本、类别分布不均、小样本等问题会同步显示在数据集详情页和毕设向导数据页，并写入报告的研究局限。
- **图像质量检查**：图像数据集会额外检查损坏图、内容重复图和异常尺寸图，并生成可执行的清理建议；大图像数据集按类别分层抽样体检，避免界面卡顿。
- **报告交付自检**：报告工坊会按题目、作者信息、数据集、基线/改进/消融、重复实验、测试集指标、训练曲线和随机种子记录逐项提示；阻断项和建议项分开展示，点生成前先看见风险。
- **离线包启动修复**：PyYAML 改为按需加载，普通表格/文本/报告任务不再因为缺少该可选依赖而启动失败；新增 `packaging/verify_offline.py` 发布烟测脚本。

## 资产

| 文件 | 说明 |
| --- | --- |
| `ThesisForge-v0.5.1-win-x64.exe` | 独立单文件版：自带 Python 与表格/文本/报告全部依赖，默认桌面窗口（不含 PyTorch） |
| `ThesisForge-v0.5.1-win64-offline.zip` | Windows 离线整合包：内嵌 Python，解压后双击 `ThesisForge.exe`，可自行安装 CPU/GPU 版 PyTorch 做视觉训练 |

## 已知边界

- 独立单文件版为控制体积不包含 PyTorch/Ultralytics，视觉任务请使用离线整合包并按提示安装训练依赖。
- 报告中的研究性解读基于当前实验记录生成；论文提交前仍建议用自己的语言润色，并结合领域背景补充文献。
