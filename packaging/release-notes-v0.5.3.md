# 毕设工坊 ThesisForge v0.5.3

v0.5.3 完善 YOLO26 全尺寸模型接入与本地 `.pt` 权重扫描，并修复自动调参接口的本地模型权重路径问题。

## 本次新增

- **YOLO26 全尺寸覆盖**：目标检测与实例分割均支持 `n / s / m / l / x` 五档模型。
- **本地模型扫描增强**：标准命名权重和自定义 `.pt` 权重都可从 `models/`、`data/models/`、项目根目录或 `THESISFORGE_MODEL_DIR` 指定目录读取；`best.pt` / `last.pt` 不会被误扫成模型。
- **训练前模型检测**：新建实验时会在提交前检查模型是否存在，并直接使用扫描到的权重路径。
- **调参接口修复**：自动调参现在同样支持本地视觉模型，且不再因未定义权重路径而失败。
- **UI 模型提示**：模型列表页会说明本地权重放置位置和环境变量用法。

## 已知边界

- 独立单文件版为控制体积不包含 PyTorch/Ultralytics，视觉任务请使用离线整合包并按提示安装训练依赖。
- 报告中的研究性解读基于当前实验记录生成；论文提交前仍建议用自己的语言润色，并结合领域背景补充文献。
