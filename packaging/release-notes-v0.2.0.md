# 毕设工坊 ThesisForge v0.2.0

面向人工智能专业毕业设计的一站式本地可视化工作台：数据集 → 表单化训练 → 实验对比 → AIGC 自检 → 学位论文 Word 初稿。纯本地运行，数据不出电脑。

## 下载

| 文件 | 适用 | 说明 |
| --- | --- | --- |
| `ThesisForge-v0.2.0-win64-offline.zip` | Windows 10/11 64位 | **推荐**：内嵌 Python 与全部依赖，解压即用，无需安装 Python |
| Source code (zip/tar.gz) | 有 Python 3.10+ 环境 | `pip install -r requirements.txt` 后运行 |

## 离线包使用

1. 解压到任意目录（路径不要含特殊字符更稳妥）
2. 双击 `启动毕设工坊.bat`，浏览器自动打开 http://127.0.0.1:8765
3. 首次使用会弹出新手引导，照着总览页清单即可完成第一次实验

图像分类训练需要 PyTorch（表格/文本任务开箱即用）：
- NVIDIA 显卡：`安装图像训练-GPU版.bat`（约 2.5GB）
- 无独立显卡：`安装图像训练-CPU版.bat`（约 200MB）

## 本版亮点

- **数据集中心**：6 个内置数据集一键载入；本地 CSV/Excel/图像 zip 导入；公网直链下载（SSRF 防护）；自动 EDA
- **模型训练**：14 个模型表单调参，后台训练实时曲线，自动 GPU
- **实验记录**：全量留档，消融/对比实验直接出表
- **AI 分析**：OpenAI 兼容接口（DeepSeek/智谱/通义等），无 Key 时降级规则分析器
- **报告工坊**：学位论文规范 docx——目录域、中英文摘要、三线表、GB/T 7714 参考文献、页眉页码、致谢
- **AIGC 自检与降 AI 味**：模板套话/句长均匀度/列表体检测与改写（思路参考开源 HC3 检测数据集与 burstiness 原理；不承诺通过任何检测系统）
- **毕设指南**：九步路线图 + 24 条常见问题预判

## 隐私与安全

- 所有数据、实验记录、API Key 只保存在本机 `data/` 目录（不上传）
- AI Key 支持环境变量方式，源码零凭据
- 出站下载仅允许公网 http/https，拒绝内网/保留地址
