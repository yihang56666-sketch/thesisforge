# 毕设工坊 ThesisForge v0.4.1

v0.4.1 在引导式向导上补齐了新手最需要的表单和兜底：三种任务都有一条无脑跑通的路径，向导填过的预处理与训练策略会直接带到训练页，实验留下可重复、可对比、可写论文的完整记录。

## 本次新增

- **向导步骤 3/4/5 表单化**：数据预处理与划分、任务与网络架构、优化与训练策略都可直接填写并自动保存；训练页自动沿用向导里的预处理策略。
- **网络代价预览**：选好网络后立即显示参数量、建议轮次、训练速度与设备友好度，避免普通电脑选了过重模型后空等。
- **环境自检**：训练前检查 Python / PyTorch / CPU-GPU / torchvision 等环境，缺什么给出一句人话提示，而不是中途中报错。
- **论文写法提示**：每个向导步骤右上角提供「这一步论文怎么写」，生成的段落可直接扩展进报告。
- **内置示例三件套**：表格（葡萄酒）、图像（水面检测演示）、文本示例数据均可一键载入，没带数据也能完整跑通毕设流程。
- **水面检测完整演示实验**：`scripts/run_water_surface_demo.py` 已实际跑通基线/改进两组实验，输出实验对比表、各项图表、论文报告草稿与样例图（见 `docs/水面检测_样例图.png` 等演示文件）。

## 本次修复

- 向导第 6 步在「还没有实验」和「已有实验」两种状态下都补充了实验命名与分组（基线 / 改进 / 消融）提示。
- 失败训练记录现在带 `failure_hint`，实验详情页会直接显示失败原因与处理建议，不再只看到一串报错。

## 资产

| 文件 | 说明 |
| --- | --- |
| `ThesisForge-v0.4.1-win-x64.exe` | 独立单文件版：自带 Python 与表格/文本/报告全部依赖，默认桌面窗口（不含 PyTorch） |
| `ThesisForge-v0.4.1-win64-offline.zip` | Windows 离线整合包：内嵌 Python，解压后双击 `ThesisForge.exe`，可自行安装 CPU/GPU 版 PyTorch 做图像训练 |

## 已知边界

- 独立单文件版为控制体积不包含 PyTorch，图像分类请使用离线整合包。
- 桌面窗口依赖 WebView2；未安装时程序会自动改用浏览器打开，不影响使用。
- 内置水面检测演示使用合成数据，用于跑通流程与界面展示，不能作为真实工程结论。
- AIGC 检测工具无法保证学校检测系统结果，AI 初稿应结合自己的理解重写并遵守学校规定。
