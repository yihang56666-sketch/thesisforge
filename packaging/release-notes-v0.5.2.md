# 毕设工坊 ThesisForge v0.5.2

v0.5.2 聚焦报告前置自检和领域化论文表达，让报告在生成前先暴露交付风险，并在水面/水域、无人机/航拍等真实场景下生成更贴近论文写作的内容。

## 本次新增

- **报告交付自检**：报告工坊按题目、作者信息、数据集、基线/改进/消融、重复实验、测试集指标、训练曲线和随机种子记录逐项提示；阻断项和建议项分开展示，点生成前先看见风险。
- **领域场景增强**：题目或数据集命中水面、水域、无人机/航拍场景时，报告会补充倒影、反光、小目标、光照变化、视角与高度变化等实际干扰因素，并写入研究局限。
- **任务方法论增强**：报告按任务家族补充实验设计说明，覆盖目标检测、语义分割、图像分类、文本分类、表格分类和时间序列预测。
- **文献综述增强**：按任务族生成文献综述段落，水面/无人机场景会进一步落到实际干扰因素与常用研究思路。
- **研究方法与技术路线增强**：报告新增研究方法与技术路线章节，能说明从数据准备、模型训练到评估和对比的完整实验设计。
- **实验分析增强**：单个实验分析直接报告主指标、其余指标、相对基线变化、过拟合/欠拟合迹象、类别不平衡与任务专属指标解释。
- **图表引用段落**：每个实验的图表自动生成“图 X 至图 Y”的分析引导，提醒结合指标表、训练曲线和数据划分交叉核对。
- **发布验证增强**：新增 `packaging/verify_offline.py` 发布烟测脚本，覆盖离线包启动、表格/文本训练、实验对比与报告生成。

## 资产

| 文件 | 说明 |
| --- | --- |
| `ThesisForge-v0.5.2-win-x64.exe` | 独立单文件版：自带 Python 与表格/文本/报告全部依赖，默认桌面窗口（不含 PyTorch） |
| `ThesisForge-v0.5.2-win64-offline.zip` | Windows 离线整合包：内嵌 Python，解压后双击 `ThesisForge.exe`，可自行安装 CPU/GPU 版 PyTorch 做视觉训练 |

## 已知边界

- 独立单文件版为控制体积不包含 PyTorch/Ultralytics，视觉任务请使用离线整合包并按提示安装训练依赖。
- 报告中的研究性解读基于当前实验记录生成；论文提交前仍建议用自己的语言润色，并结合领域背景补充文献。
