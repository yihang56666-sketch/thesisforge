# 毕设工坊 ThesisForge v0.4.0

v0.4.0 把毕设上手方式改成「引导式」：第一次打开软件直接进入 10 步毕设向导，从立项、数据、网络架构、优化策略一路走到报告工坊，每步都有任务可提交、进度自动保存；神经网络目录也补全到表格/图像/文本各类任务和通用优化方案。

## 本次新增

- **10 步毕设向导**：立项 → 数据 → 数据预处理与划分 → 任务与网络架构 → 优化与训练策略 → 训练与监控 → 评估分析 → 消融实验 → 实验对比 → 报告工坊；步骤状态与表单内容自动保存，重启后继续。
- **全神经网络目录**：19 个模型覆盖表格分类/回归、文本分类、图像分类；支持自定义优化器、学习率调度、早停、梯度裁剪、随机种子等通用训练策略。
- **通用训练引擎**：表格/文本 sklearn 训练与图像/文本 PyTorch 训练统一封装的作业引擎，配置、日志、指标、图表留档口径一致。
- **一键重复与消融实验**：实验详情页可重跑同一配置作为重复实验，也可一键生成基线消融，自动补全分组与备注。
- **完整演示实验脚本**：`scripts/run_thesis_demo.py` 已跑通 11 个实验（图像基线/改进/3 次重复/4 项消融、表格基线/MLP），输出实验对比表和论文报告草稿。

## 本次修复

- 修复 pywebview 原生空弹窗：部分场景会先弹一个没有内容的 `prompt/confirm` 窗口，现改为应用内确认面板，不再遮挡操作。
- 修复消融实验随机种子不一致问题，重复/消融实验现在使用可控随机种子，对比更严谨。

## 资产

| 文件 | 说明 |
| --- | --- |
| `ThesisForge-v0.4.0-win-x64.exe` | 独立单文件版：自带 Python 与表格/文本/报告全部依赖，默认桌面窗口（不含 PyTorch） |
| `ThesisForge-v0.4.0-win64-offline.zip` | Windows 离线整合包：内嵌 Python，解压后双击 `ThesisForge.exe`，可自行安装 CPU/GPU 版 PyTorch 做图像训练 |

## 已知边界

- 独立单文件版为控制体积不包含 PyTorch，图像分类请使用离线整合包。
- 桌面窗口依赖 WebView2；未安装时程序会自动改用浏览器打开，不影响使用。
- 演示实验使用合成图像数据，用于跑通流程与界面展示，不能作为真实医学结论。
- AIGC 检测工具无法保证学校检测系统结果，AI 初稿应结合自己的理解重写并遵守学校规定。
