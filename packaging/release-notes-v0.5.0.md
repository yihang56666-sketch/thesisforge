# 毕设工坊 ThesisForge v0.5.0

v0.5.0 补齐像素级语义分割路线，并把 EXE 打包链路与版本发布说明继续收敛。

## 本次新增

- **像素级语义分割**：新增 U-Net 模型，支持 `images/ + masks/ + classes.txt` 的像素级掩码数据集导入。
- **语义分割指标**：训练与评估输出 IoU、Dice、像素准确率，报告按像素级分割口径描述方法与实验结果。
- **预测可视化**：语义分割实验生成预测掩码/叠加可视化，便于答辩演示与结果分析。
- **打包修复**：独立 EXE 的训练子进程白名单补上 `train_semantic.py`，U-Net 语义分割在打包后不再被误判为非法训练模块。
- **模型目录更新**：README 与实际模型目录对齐为 28 个模型，并补齐语义分割能力说明。

## 资产

| 文件 | 说明 |
| --- | --- |
| `ThesisForge-v0.5.0-win-x64.exe` | 独立单文件版：自带 Python 与表格/文本/报告全部依赖，默认桌面窗口（不含 PyTorch） |
| `ThesisForge-v0.5.0-win64-offline.zip` | Windows 离线整合包：内嵌 Python，解压后双击 `ThesisForge.exe`，可自行安装 CPU/GPU 版 PyTorch 做视觉训练 |

## 已知边界

- 独立单文件版为控制体积不包含 PyTorch/Ultralytics，视觉任务请使用离线整合包并按提示安装训练依赖。
- U-Net 显存占用高于分类 CNN；小显卡建议降低输入尺寸或批大小。
- 语义分割标注质量会直接影响 IoU/Dice，建议训练前先检查掩码类别与图像尺寸是否一致。
